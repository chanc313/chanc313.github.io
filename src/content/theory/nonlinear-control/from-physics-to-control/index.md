笔记 · 控制问题的建模与分析流程 · 对照 Khalil《Nonlinear Systems》第 3 版、Kelly–Santibáñez–Loría《Control of Robot Manipulators in Joint Space》

本篇整理一个控制问题从物理方程到闭环分析的完整流程：每一步的数学对象和它回答的问题，以单关节为例走完全程，并给出 n 自由度机械臂的对应形式。

| 步骤 | 数学对象 | 回答的问题 |
|---|---|---|
| 1 物理方程 | 微分方程 | 系统怎么运动 |
| 2 输入与输出 | u、y | 能改变什么，关心什么 |
| 3 状态空间 | ẋ = f(x, u)，y = h(x) | 化为一阶向量方程 |
| 4 平衡点与线性化 | (x*, u*)，A、B | 在哪里能停住，附近如何运动 |
| 5 开环分析 | 特征值、传递函数、可控性 | 不加控制时是否稳定，能否控制 |
| 6 控制律 | u = k(x, x_d) | 如何选择输入 |
| 7 闭环分析 | ẋ = f_cl(x) | 加控制后是否稳定，在多大范围内 |

贯穿全篇的例子：单关节，质量 m 集中于杆端，杆长 l，关节粘性摩擦系数 b，θ 自竖直向下量起，电机施加力矩 τ。数值取 m = l = 1，b = 0.5，g = 9.81。

## 1 物理方程

**建模**：由物理定律写出运动方程。刚体系统用牛顿–欧拉方程或拉格朗日方程。

*单关节，对关节取力矩平衡：*

$$
m l^2 \ddot\theta = \tau - b\dot\theta - m g l \sin\theta
$$

**建模假设**：刚体、质量集中于杆端、摩擦为粘性、电机力矩可以任意指定。每条假设都是一个模型误差来源，自适应控制与鲁棒控制处理的就是这些误差。

## 2 输入与输出

**输入 u**：可以由控制器指定的量。这里 u = τ。

**输出 y**：关心或能测量的量。这里 y = θ。

**被控对象**：第 1 步的方程本身。它规定 u 如何影响系统，但不规定 u 取什么值。

*常见错误：把 τ 当作 θ̈ 的别名。τ 是输入，θ̈ 由整个方程决定：ml²θ̈ = τ − bθ̇ − mgl sin θ，τ 一般不等于 ml²θ̈。*

## 3 状态空间

**状态**：一组最少的变量，给定它们在 t₀ 的值和 t ≥ t₀ 的输入，即可唯一确定此后的行为。

**化为一阶方程**：n 阶方程取 x₁ = 变量本身，x₂ = 它的一阶导数，……，xₙ = 它的 n − 1 阶导数，得 n 个一阶方程。

*单关节（二阶）：x₁ = θ，x₂ = θ̇，*

$$
\dot x = f(x, u) = \begin{bmatrix} x_2 \\ \dfrac{1}{ml^2}\left(u - b x_2 - mgl\sin x_1\right) \end{bmatrix}, \qquad y = x_1
$$

**n 自由度机械臂**：x = (q, q̇) ∈ ℝ²ⁿ，u = τ，

$$
\dot x = \begin{bmatrix} \dot q \\ M(q)^{-1}\left(\tau - C(q,\dot q)\dot q - g(q)\right) \end{bmatrix}
$$

M(q) 对称正定，M⁻¹ 存在。

## 4 平衡点与线性化

**平衡点**：满足 f(x*, u*) = 0 的 (x*, u*)。输入不为零时，平衡点要和对应的常值输入一起求。

*单关节停在 θ\*：x₂\* = 0，u\* = mgl sin θ\*。要停在水平位置 θ\* = 90°，必须一直输出 u\* = 9.81 N·m 来抵抗重力。*

**线性化**：在 (x*, u*) 处一阶展开，δx = x − x*，δu = u − u*：

$$
\delta\dot x = A\,\delta x + B\,\delta u, \qquad A = \frac{\partial f}{\partial x}\Big|_*, \quad B = \frac{\partial f}{\partial u}\Big|_*
$$

A、B 是雅可比，逐元素求偏导得到。

*单关节：*

$$
A = \begin{bmatrix} 0 & 1 \\ -\dfrac{g}{l}\cos\theta^* & -\dfrac{b}{ml^2} \end{bmatrix}, \qquad B = \begin{bmatrix} 0 \\ \dfrac{1}{ml^2} \end{bmatrix}
$$

*常见错误：把 sin x₁ 写成 (sin x₁/x₁)·x₁，再把 sin x₁/x₁ 当作偏导。这是状态相关系数（SDC）形式，不是雅可比。两者只在原点相等。*

## 5 开环分析

**特征值**：A 的特征值 λ 是特征多项式 det(λI − A) = 0 的根。

**线性化判稳定**：所有 Re λ < 0 ⇒ x* 局部指数稳定；存在 Re λ > 0 ⇒ 不稳定；有 Re λ = 0 且其余 Re λ ≤ 0 ⇒ 不能下结论，回到非线性方法。

*单关节，u = u\* 保持不变：*

| 平衡点 | 特征值 | 结论 |
|---|---|---|
| θ* = 0（下垂） | −0.25 ± 3.12j | 稳定焦点 |
| θ* = 180°（竖直向上） | 2.89，−3.39 | 鞍点，不稳定 |

**传递函数**：对线性化方程取拉普拉斯变换（零初值），sX(s) = AX(s) + BU(s)，得

$$
G(s) = \frac{Y(s)}{U(s)} = C\,(sI - A)^{-1}B
$$

C 是输出矩阵（y = Cx）。

> **s 与 λ 的关系**。(sI − A)⁻¹ 的每个元素都以 det(sI − A) 为分母，所以 G(s) 的极点就是 det(sI − A) = 0 的根，即 A 的特征值。在时域中，设 x = v·e^{λt} 代入 ẋ = Ax，得 λv = Av，同一个结论。
>
> 两者不是同一个对象：s 是取遍复平面的自变量，λ 是特定的几个根。它们共用同一个多项式，所以控制领域常把特征多项式直接写成关于 s 的形式。

*单关节在 θ\* = 0：G(s) = 1/(s² + 0.5s + 9.81)，极点 −0.25 ± 3.12j，和上表一致。*

**可控性**：线性化系统可控 ⇔ rank[B, AB, …, Aⁿ⁻¹B] = n。可控时，可以用状态反馈任意配置闭环特征值。

*单关节：[B, AB] = [[0, 1], [1, −0.5]]，秩为 2，可控。*

*稳定和可控是两回事：竖直向上的平衡点不稳定，但可控，所以能用控制把它稳住（如倒立摆）。*

## 6 控制律

**控制律**：u = k(x, x_d)，x_d 为参考值。

**闭环系统**：把控制律代入对象，ẋ = f(x, k(x, x_d))。闭环里不再有外部输入，是一个新的自治系统（x_d 为常数时）。

**f_cl 由控制律决定**：f_cl(x) = f(x, k(x, x_d))。对象 f 不变，每换一个控制律 k 得到一个不同的闭环，需重新分析。设计控制律即选择一个可分析、性质好的 f_cl。

| 控制律 | 单关节形式 | 闭环（m = l = 1，e = θ_d − θ） |
|---|---|---|
| PD | τ = K_p e − K_dθ̇ | θ̈ = K_p e − (K_d + b)θ̇ − g sin θ，平衡点不在 θ_d |
| PD 加重力补偿 | τ = K_p e − K_dθ̇ + mgl sin θ | θ̈ = K_p e − (K_d + b)θ̇，平衡点在 θ_d |
| 逆动力学（计算力矩） | τ = ml²v + bθ̇ + mgl sin θ，v = θ̈_d + K_d ė + K_p e | ë + K_d ė + K_p e = 0，线性 |
| 自适应 | 同上，参数用在线估计值 | 参数未知 |
| 鲁棒 / 滑模 | 同上，加一项克服参数误差上界 | 参数不确定但有界 |

*逆动力学的思路：用 τ 抵消对象的全部非线性，把闭环变成指定的线性系统。取 K_p = 25、K_d = 10，闭环特征值为 −5、−5（ω_n = 5，ζ = 1）。它要求模型准确；模型不准时用自适应控制或鲁棒控制。*

**n 自由度**：上表各行把标量换成矩阵即可，例如逆动力学 τ = M(q)v + C(q, q̇)q̇ + g(q)。

## 7 闭环分析

对闭环 ẋ = f_cl(x) 重复第 4、5 步：

1. **求平衡点**：f_cl(x*) = 0。可能不止一个（[稳定性分析](/theory/nonlinear-control/stability/)第 8 节，K_p = 3 时有三个）。
2. **线性化**：A_cl = ∂f_cl/∂x = A + B·∂k/∂x。控制律改写的是 A。线性状态反馈 u = −Kx 时 A_cl = A − BK。
3. **线性化不能下结论，或者需要全局结论时**：用李雅普诺夫直接法、LaSalle 原理。机械臂常取 V = 动能 + 人为势能，求导时用 Ṁ − 2C 斜对称消去 C。
4. **吸引域**：局部结论成立的范围，用 V 的水平集估计。
5. **时变闭环**（轨迹跟踪，x_d 随时间变化）：LaSalle 不适用，改用 Barbalat 引理。

## 小结：每一步之间容易断的地方

- 1 → 2：τ 是输入，不是对象的一部分。
- 3 → 4：有输入时，平衡点是 (x*, u*) 一对。
- 4：雅可比要逐元素求偏导，SDC 形式不是雅可比。
- 5：特征多项式用 λ 或 s 都可以，原因见第 5 节的说明。
- 5 → 6：稳定性是对象（或闭环）的性质，可控性是能否用输入改变它，两者独立。
- 6 → 7：代入控制律后得到的是一个新系统，分析的对象是它，不是开环对象。
- 7：线性化只给局部结论，并且只在 Re λ ≠ 0 时有效。
