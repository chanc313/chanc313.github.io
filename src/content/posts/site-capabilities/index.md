@me

我们现在和未来拥有完全的控制力吗？无论是改排版、布局，放组件，放动态图，放 BGM，放视频或者放小游戏，都可以？

@ai

**有完全的控制权。** 网站的每一行代码都在仓库里，没有被锁死的主题。最终产物是普通的 HTML、CSS 和 JS 文件，浏览器能运行的都能放：

| 想放的 | 能否 | 做法 |
|---|---|---|
| 改排版、布局 | 能 | 改 `.astro` 组件和 CSS |
| 自定义组件 | 能 | 在 `components/` 写新组件；文章内直接插组件需加 MDX 支持 |
| 动态图 | 能 | GIF、WebP、视频放进 `public/` |
| BGM | 能 | `<audio>` 标签。浏览器禁止有声自动播放，必须由访客点击后才会播放 |
| 视频 | 能 | 小视频直接放仓库；大视频放 B 站或 YouTube 再嵌入 |
| 小游戏 | 能 | JS 或 Canvas 编写，可单独成页或嵌入文章 |

真正的边界来自 GitHub Pages：

- **只托管静态文件，没有服务器和数据库。** 评论、访问统计等需要存储数据的功能，要借助第三方服务（如用 giscus 做评论）。
- **容量限制：** 单个文件不超过 100MB，整站建议在 1GB 以内，每月流量软上限 100GB。
